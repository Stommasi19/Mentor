## Limits and learning checkpoint

Session state lives in conversation context and is supplied to each control; it
is not another disk schema. Native tests demonstrate retention for this host/model
combination, not an enforceable guarantee across all LLMs. Coaching pause retains
necessary clarification, code/docs standards and behavioral checks.

Project identity hashes the canonical Git common directory (or non-Git starting
root). Preferences live at `<data-root>/projects/<id>/preferences.json`; the local
adapter defaults to `~/.mentor` or an absolute `MENTOR_DATA_DIR`. Worktrees share,
clones differ, non-Git nested starts differ, moved roots may need reselection/reset.
There is no migration or live broadcast. Atomic writes are last-completed-write
wins, without concurrent field merging; readback mismatch is unverified persistence.
Invalid records stay intact until explicit reset. Failed saves/resets apply locally
and report unsaved state; another conversation retains its own overrides on refresh.

Automatic mid-turn compaction, other hosts/OS/languages/providers, concurrent stress,
and human comprehension remain pending. The previously exercised reserved examples
are regression checks, not newly blind transfer evidence. No distribution work was
added. M03/M04 are still needed for the complete first local usable version.

A useful learner review is to trace why changing the saved level cannot copy a
temporary coaching pause into the other saved field, and why B's local override
survives A's reset. Agent explanation alone provides no evidence of comprehension.
